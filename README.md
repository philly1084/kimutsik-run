# Kimutsik Run

A cheerful dog-team sea ice game made to share. It works in a phone or desktop browser, including offline if you save the page.

- **3D:** https://philly1084.github.io/kimutsik-run/
- **2D:** https://philly1084.github.io/kimutsik-run/2d/

Steer the team, gather Arctic char and partridgeberries, and go around cracks and snowdrifts. Short runs, no fail-shaming. A few Labrador Inuttitut words are listed in the game, with sources in Credits.
